EGAT Tree Survey Web App (PWA)
=============================

เว็บแอปสำรวจต้นไม้สำหรับเผยแพร่ผ่าน HTTPS และเปิดได้จาก Android, iPhone/iPad และคอมพิวเตอร์

ไฟล์สำคัญ
- index.html: แอปสำรวจต้นไม้
- manifest.webmanifest: ชื่อ ไอคอน และการเปิดเป็นเว็บแอป
- service-worker.js: แคชไฟล์หลักเพื่อช่วยเปิดหลังจากเข้าเว็บออนไลน์ครั้งแรก
- icons/: ไอคอนแอป 192 และ 512 px

การเก็บข้อมูล
- รายการสำรวจและรายการต้นไม้บันทึกด้วย localStorage ในเบราว์เซอร์/โปรไฟล์ของเครื่องนั้น
- ลิงก์เดียวกันเปิดได้หลายเครื่อง แต่ข้อมูลที่บันทึกแยกกัน ไม่ได้ส่งไปฐานข้อมูลกลาง
- ข้อมูลอาจหายหากล้างข้อมูลเว็บไซต์/เบราว์เซอร์หรือถอน/ล้างข้อมูลแอป ควรส่งออก CSV สำรองเป็นระยะ
- เปิดเว็บไซต์ขณะออนไลน์ให้โหลดครบก่อนลงพื้นที่ และทดสอบโหมดเครื่องบินก่อนใช้งานจริง
- รายการต้นไม้ในแอปยังเป็นรายการตัวอย่าง ไม่ใช่บัญชี กกพ. ฉบับทางการ ต้องนำเข้ารายการที่หน่วยงานอนุมัติก่อนใช้งานจริง
- แอปไม่คำนวณหรือรับรองราคาค่าทดแทน และไม่เชื่อมต่อระบบภายใน กฟผ.

วิธีเผยแพร่ด้วย GitHub Pages
1. เข้า https://github.com/ แล้วสมัคร/เข้าสู่ระบบ
2. กด + > New repository ตั้งชื่อ egat-tree-survey
3. เลือก Public หากใช้ GitHub Free สำหรับ Pages แล้วกด Create repository
4. แตก ZIP นี้ในคอมพิวเตอร์หรือโทรศัพท์
5. ใน repository กด Add file > Upload files แล้วอัปโหลดไฟล์ทั้งหมดจากใน ZIP โดยให้ index.html อยู่ระดับบนสุด (root) และต้องมีโฟลเดอร์ icons
6. กด Commit changes
7. เข้า Settings > Pages
8. ใน Build and deployment เลือก Source: Deploy from a branch
9. เลือก Branch: main และ Folder: /(root) แล้วกด Save
10. รอให้ GitHub Pages เผยแพร่ จากนั้นเปิด URL ที่หน้า Pages แสดง (มักเป็น https://ชื่อบัญชี.github.io/egat-tree-survey/)
11. ทดสอบ URL บนอุปกรณ์ที่ต้องการทั้งออนไลน์และโหมดเครื่องบิน

วิธีเปิด/ติดตั้งตามอุปกรณ์
Android:
- เปิด URL ด้วย Chrome ขณะออนไลน์
- แตะเมนู ⋮ > Install app หรือ Add to Home screen แล้วทำตามหน้าจอ

iPhone/iPad:
- เปิด URL ด้วย Safari (แนะนำสำหรับเพิ่มเป็นเว็บแอป)
- แตะ Share > Add to Home Screen > Add; ถ้ามีตัวเลือก Open as Web App สามารถเปิดได้
- จากนั้นเปิดผ่านไอคอนบนหน้าจอหลักได้ การเพิ่มไอคอนทำแยกในแต่ละเครื่อง

Windows/macOS/Linux:
- เปิด URL ด้วย Chrome หรือ Edge เพื่อใช้งานเป็นเว็บไซต์
- หากเบราว์เซอร์แสดงไอคอน Install ในแถบที่อยู่หรือเมนู ให้เลือก Install เพื่อเปิดเป็นเว็บแอปได้ หรือใช้เว็บไซต์ในแท็บตามปกติ

การส่งให้คนอื่น
- ส่ง URL จริงจาก GitHub Pages ผ่าน LINE หรือช่องทางที่ต้องการ
- ทุกคนใช้ URL เดียวกันได้ แต่ข้อมูลในแอปของแต่ละเครื่อง/โปรไฟล์เบราว์เซอร์จะแยกกัน

ข้อควรระวังความเป็นส่วนตัว
GitHub Pages เป็นเว็บไซต์สาธารณะ ผู้ที่มีลิงก์สามารถเปิดแอปได้ และไฟล์ที่อัปโหลดใน repository อาจถูกอ่านได้ อย่าใส่ข้อมูลลับหรือข้อมูลสำรวจจริงลงในไฟล์เว็บไซต์ เวอร์ชันนี้บันทึกข้อมูลที่ผู้ใช้กรอกไว้ในเบราว์เซอร์ของเครื่อง ไม่ได้มีระบบบัญชีผู้ใช้หรือฐานข้อมูลกลาง
